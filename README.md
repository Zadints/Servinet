# Servinet

Aplicación de escritorio desarrollada en Java utilizando JavaFX para la gestión de servicios y administración de usuarios.

## Tecnologías utilizadas
[![My Skills](https://skillicons.dev/icons?i=java)](https://skillicons.dev)
- **Java 21**
- **JavaFX 21**
- **Maven**
- **SQL Server**
- **JDBC**
- **FXML**
- **CSS**
- **Ikonli**
- **Argon2** para el almacenamiento seguro de contraseñas
- **YAML** para la configuración de la aplicación
- **Clean Architecture**

## Requisitos

Antes de ejecutar el proyecto debes tener instalado:

- Java JDK 21
- Maven
- SQL Server
- SQL Server Management Studio (SSMS), recomendado para administrar la base de datos

Puedes comprobar las versiones con:

```bash
java -version
mvn -version
```
